What changed

The rerun shows immediate fan-out to three extract tasks, then steady slot refill as each task finishes. This is the log pattern we expected after moving blocking task execution into threads.

What stayed the same

The plan shape did not change: 25 extract tasks, 1 aggregate analyze task, and 1 final synthesize task. Analyze still depends on all extracts, and synthesize still depends on analyze.

Main payoff

The end-to-end runtime dropped from 154.366 seconds to 70.022 seconds. The win comes from overlapping independent extract tasks, not from faster individual task latency.
