⚠️ 为什么 risk_assessment = "write"？

原因：该任务会产出 approval_status = PENDING_HUMAN_APPROVAL
后果：触发人工审批流程，属于有副作用的操作
与其他区别：其余 8 个只产出文本分析结果，不改变任何审批状态
Phase 3 影响：analyst 角色不能直接调用此任务

✅ 为什么用默认值？

向后兼容：所有现有 TaskSpec 无需修改，自动获得 "read" 默认值
渐进式：先能跑，后补充完整元数据
安全：未填写的任务默认最低权限 "read"，不会意外暴露写权限
测试：test_tasks_metadata.py 验证所有 9 个任务都已显式填写
