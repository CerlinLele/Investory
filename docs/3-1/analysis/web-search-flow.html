web_search 流程图（Agent 决策 vs Tool 执行）

重点：Agent 决定“是否搜、搜什么”；Tool 决定“按哪个 provider 顺序去搜并 fallback”。

上层决策链（Agent / Runtime）
/tasks 请求
task_type=web_search
→
Gateway

→
decision_planner

→
RunWebSearchExecutor
提取 query/top_k/provider_hint
工具执行链（Tool / Network）
search_web(query, top_k, provider_hint)
→
_provider_candidates()
provider_hint 优先
→
按 web_search_provider_order
逐个 provider fallback
→
guarded_get()
allowlist + timeout + logging
解析 HTML -> title/snippet/source
→
成功: ToolResult.ok=true
results + provider_attempt_order
→
失败: ToolResult.ok=false
error_type/retryable
→
Executor 返回 ActionResult
success / requires_user_input
结论：本阶段已包含“具体去哪搜”的执行逻辑，但它由 Tool 层（provider_hint + provider_order）驱动，不是 planner 每轮智能选择具体 provider。
