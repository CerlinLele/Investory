# docs/3-1 目录索引

这个目录按用途分层，避免计划、分析、交付和日志混在一起。

## 结构

- `worklog/`
  - 过程记录、执行日志、阶段性复盘。
- `plans/`
  - 实施计划、落地清单、重构方案。
- `analysis/`
  - 代码定位、流程分析、图示说明。
- `delivery/`
  - 交付检查清单、PR 草稿。
