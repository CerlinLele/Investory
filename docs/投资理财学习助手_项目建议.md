# 投资理财学习助手 项目建议

## 结论

这个项目可行，而且比“泛助手”更适合边学边做，但前提是把它定义成**学习助手**，而不是“荐股/代客决策机器人”。

## 建议的项目边界

### 做什么

- 投资理财知识问答：基金、债券、ETF、资产配置、风险收益、估值、复利、仓位管理
- 新闻、研报、财报学习整理：提炼重点、解释术语、生成学习笔记
- 风险认知训练：用问卷和案例帮助用户理解风险偏好
- 模拟练习：虚拟组合、回测入门、情景分析、复盘记录
- 学习路径规划：按新手、进阶、专题生成学习计划和练习

### 先不要做什么

- 直接给出“买哪个、什么时候买、买多少”
- 个性化投资建议
- 自动下单
- 高风险策略推荐
- 用不透明 prompt 直接输出投资结论

## 为什么适合作为课程项目

这个项目和课程大纲的主线高度匹配：

- `单次请求`：解释一个理财概念，或总结一篇研报/财报
- `规划/结构化输出`：判断用户是在问概念、做对比，还是要生成学习计划
- `工具/MCP`：接行情、财经日历、基金资料、新闻源
- `FastAPI/Gateway`：做成可用服务
- `Runtime/Skills`：沉淀“基金分析 Skill”“财报阅读 Skill”“资产配置 Skill”
- `状态管理`：记录学习进度、风险偏好、已读内容
- `Eval`：校验回答是否事实错误、是否越界成投资建议
- `安全基线`：强制风险提示、拒绝直接荐股、标注数据时间

## 推荐的第一版 MVP

第一版建议只做 4 个能力：

1. 理财概念问答
2. 财经文章或财报摘要
3. 基金或 ETF 基础信息整理
4. 学习计划与复盘记录

## 后续迭代方向

等第一版稳定后，再逐步增加：

1. 行情与新闻工具接入
2. 模拟组合
3. 风险测评
4. 结构化分析模板

## 核心原则

**先做“帮助用户学会判断”，不要做“替用户下判断”。**
