run() 主流程

读图说明

  • 每轮都先过 check_stop_condition()，再决定是否继续。
  • 失败路径分两类：校验失败、执行失败；都走同样的重试门控。
  • 非重试失败会把状态落到 FAILED，下一轮开始就被 stop 条件截停。
  • CALL_TOOL 既记详细记录，也更新 tool_call_count，用于预算收敛。
  • 成功路径会重置 retry_count，并按动作落到 FINALIZED / WAITING_FOR_USER / RUNNING。

蓝色菱形：条件判断

绿色块：成功收尾

黄色块：失败处理（可能重试）

粉色块：停止并返回
