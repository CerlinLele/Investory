Investory Production 级 ReAct Loop 流程图

flowchart TD
    A[POST /learning-entry] --> B[初始化 ReactLoopState]
    B --> C[Policy Gate: 缺字段检查]
    C -->|缺字段| D[返回 ask_for_missing_input]
    C -->|字段完整| E[Policy Gate: 投资建议/越界检查]
    E -->|越界| F[返回 refuse_and_redirect]
    E -->|可继续| G[进入 ReAct Loop]

    G --> H[step_count + 1]
    H --> I[plan_next_step]
    I --> J[validate_action]

    J -->|action=call_tool| K[Tool Registry 校验]
    K -->|失败| L[记录审计 + 结构化错误]
    K -->|通过| M[执行工具并记录 observation]

    J -->|action=execute_learning_task| N[TaskExecutor -> TaskExecutionPipeline]
    N --> O[记录 observation]

    J -->|action=finalize| P[返回 completed]
    L --> Q[check_stop_condition]
    M --> Q
    O --> Q

    Q -->|max_steps/max_tool_calls/重复动作/不可重试错误| R[返回 failed 或 max_steps_exceeded]
    Q -->|继续| G
    Q -->|满足完成条件| P
