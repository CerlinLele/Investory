Investory LangGraph LearningQaOrchestrationFlow (Layered)

拆细版：按层逐步画图，从主干到条件分支，再到子流程细化。

术语固定：`action` 不是 node，也不是 edge；`action` 是 conditional routing key（来自 `action_call.action`）。

Layer 1 - 主干骨架

先画线性骨架，不加分支。

Layer 2 - 加入条件路由点

把 `validate_action` 后面的“分流决策点”画出来。

Layer 3 - 补齐三条 action 分支

这一步再加分支节点和分支标签（routing key）。

Layer 4 - 环节拆细（实现视角）

最后把每个 LangGraph node 的内部环节拆细，便于逐节点画实现图。

建议画图顺序：先画 Layer 1 骨架，再画 Layer 2 路由点，再画 Layer 3 分支，最后按 Layer 4 对单节点做细化。
